# Credits

## Sound effects

Most clips in `sounds/` come from [freesound.org](https://freesound.org) under the
Creative Commons licences listed below. Three of them are generated by
`tools/gen-sounds.py` and belong to this project. Each file is named after the pet event
it plays for (see `eventSounds` in `Service.qml`), so a sound can be swapped without
touching code.

The three generated ones replaced clips that were CC BY-NC. NonCommercial cannot live
inside an MIT plugin -- MIT grants commercial use and NC withholds it -- so rather than
relicense somebody else's work or quietly ship the conflict, they were rewritten from
scratch as square and sine shapes. They are reproducible: run the script and you get the
same bytes.

## Sprites

Every pet, room and decor sprite is drawn here, as a text grid in `tools/sprites/`, and
built into a PNG by `tools/gen-sprites.py`. The grids are the source: one character per
pixel, sixteen by sixteen for a pet, and a per-line palette in `tools/palettes.tsv` decides
what each character means. Upstream's sprites were one bit; these are not, because five
families need to look like five families.

Six emote bubbles are the exception and are upstream's artwork, kept as committed PNGs with
no grid behind them: `emote_bored`, `emote_dirty`, `emote_hungry`, `emote_sad`,
`emote_sleepy` and `emote_stunned`. `assets/MANIFEST.tsv` marks them with the palette column
`png` for exactly that reason, and `gen-sprites.py` measures the file itself rather than
building one. `emote_nervous` is drawn here.

The characters are affectionate references to Dragon Ball. The artwork is not.
